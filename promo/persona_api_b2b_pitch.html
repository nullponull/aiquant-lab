// 02 · PROBLEM

研修・トレーニングが、現場の"想定外"に追いつかない

各業界共通の構造的課題

  • HR：圧迫候補者・うつ気味候補者への対応研修なし
  • 営業：難しい顧客タイプ別ロープレが不足
  • 教育：発達特性のある生徒対応の体系化不足
  • 医療：SP（模擬患者）が高コストでカバー不足
  • CS：怒り顧客対応のシミュレーションなし

既存ソリューションの限界

  • 動画教材 → 双方向性なし
  • SP研修 → 1セッション数万円、月1回が限度
  • AIチャット → "人間らしい"対応がない
  • 競合AIロープレ → シナリオが画一的
市場のペイン：研修コスト ×3倍、独り立ち期間 ×3倍、退職率 ×1.5倍 ── "人間のバリエーション" を扱えない研修体制が原因。
