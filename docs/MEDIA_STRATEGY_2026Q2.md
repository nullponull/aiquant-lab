## 2. 第7の壁「人の非合理性 × ペルソナ」の追加

### 2-1. なぜ第7の壁が必要か

既存6つの壁（再帰性/非定常性/グッドハート/複雑系/ファットテール/自己言及性）は **すべて「市場側の壁」** です。一方、人間の意思決定パターンは「市場参加者側の壁」であり、AIにとって最も予測しにくい変数です。

**この壁を持ち込むことで連載の射程が広がる**:
- 経済学・統計学（既存）→ 行動経済学・心理学（追加）
- 市場データ（既存）→ 行動データ・SNS データ（追加）
- 機関投資家視点（暗黙）→ 個人投資家ペルソナ（追加）

### 2-2. 第7の壁シリーズ計画（6本構成）

| # | タイトル(仮) | 検証データ | 公開予定 |
|---|------------|---------|--------|
| 番外編1 | 投資家ペルソナ2,245体を再現したら見えた壁 | DDSDK全データ | **5/21 (今週水曜)** |
| 番外編2 | 機関投資家ペルソナ vs 個人投資家ペルソナの意思決定差 | 行動ベース782ペルソナ | 6/4 |
| 番外編3 | パニック売りペルソナ100体で再現したコロナ暴落 | 過去SNS×値動き相関 | 6/18 |
| 番外編4 | 強気ペルソナ・弱気ペルソナの議論で予測精度は上がるか | LLM議論型 × ペルソナ | 7/2 |
| 番外編5 | あなた自身のペルソナを作って投資判断と乖離を測る | Persona API self-assessment | 7/16 |
| 番外編6 | 第7の壁を踏まえた連載総括 | 6本の統合考察 | 7/30 |

### 2-3. シリーズの効果

- **連載の射程**: 6つの壁 → 7つの壁、つまり「人」を含む統合フレームへ
- **書籍化価値**: 「AIで投資の壁を越える ─ 6+1の壁との対話」として出版可能
- **講演ネタ**: 金融機関・運用会社向けに高単価セミナー化
- **プロダクト訴求**: Persona API のB2B Pro/Scale プランへの自然な誘導

## 4. 業界横展開LP戦略

### 4-1. 「ペルソナで業界の壁を越える」spin-off

aiquant-lab の「壁を越える」フォーマットを他業界に移植：

```
AIで投資の壁を越える (本連載)         → 金融業界
AIで採用の壁を越える (NEW)           → HR業界
AIで営業の壁を越える (NEW)           → Sales業界
AIで教育の壁を越える (NEW)           → Education業界
AIで医療研修の壁を越える (NEW)        → Healthcare業界
```

### 4-2. 各業界LPの共通構造

1. **ヒーロー**: 業界課題 ×「ペルソナで越える」の強い表現
2. **問題提起**: 既存ソリューション（研修動画/テキスト）の限界
3. **デモ**: ペルソナとの対話モック（Interaction Model のショート動画）
4. **証拠**: 実際の改善事例 or 既存研究データ
5. **料金**: B2B プラン提示
6. **CTA**: 「無料デモ予約」フォーム → 営業ピッチへ

### 4-3. 業界別ローンチ順序

| Phase | 業界 | 理由 | ターゲット |
|-------|-----|-----|---------|
| **Phase 1 (5-6月)** | **HR (採用面接練習)** | 痛点明確、単価明確、競合弱い | 中堅企業3000社 |
| Phase 2 (6-7月) | Sales (商談ロープレ) | allforces-sales-agent との統合 | 営業組織500社 |
| Phase 3 (7-8月) | Education (家庭教師) | 個人課金あり、市場大 | 中高生家庭 |
| Phase 4 (8-9月) | Healthcare (問診練習) | 高単価、専門性で参入障壁 | 医学生・病院 |
