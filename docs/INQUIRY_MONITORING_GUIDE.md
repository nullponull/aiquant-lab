## 4. 着信モニタリングスクリプト (手動チェック用)

### Gmail IMAP 経由 (要 App Password)

```bash
# /home/sol/scripts/check_inquiry.sh
#!/bin/bash
# Gmail 未読の Inquiry/* ラベル数をカウント

python3 << 'PYEOF'
import imaplib
import os

EMAIL = 'info@ai-media.co.jp'
PASSWORD = os.environ.get('GMAIL_APP_PASSWORD')  # 別途設定

if not PASSWORD:
    print("⚠ GMAIL_APP_PASSWORD 未設定。~/.bashrc に export してください")
    exit(1)

mail = imaplib.IMAP4_SSL('imap.gmail.com')
mail.login(EMAIL, PASSWORD)

labels = ['Inquiry/HR', 'Inquiry/Sales', 'Inquiry/Education', 'Inquiry/Healthcare', 'Inquiry/Other', 'Press']
total_unread = 0
for label in labels:
    try:
        mail.select(f'"{label}"', readonly=True)
        result, data = mail.search(None, '(UNSEEN)')
        count = len(data[0].split()) if data[0] else 0
        if count > 0:
            print(f"  📩 {label}: {count} 件未読")
            total_unread += count
    except Exception as e:
        pass

mail.logout()
print(f"\n合計未読: {total_unread} 件")
PYEOF
```

### 定期チェックの cron 設定例

```cron
# 平日朝 9:00 / 昼 13:00 / 夕 17:00 に通知
0 9,13,17 * * 1-5 /home/sol/scripts/check_inquiry.sh > /tmp/inquiry_check.log
```

## 7. 商談で頻出する質問 (FAQ補足)

LP のFAQに載せていないが、商談で頻出する可能性のある質問:

### 「個人情報保護はどうなっていますか」（全業界共通）
- ペルソナはタイプ化された架空キャラクター、特定個人を再現していない
- 自社カスタムペルソナは個人情報マスキング処理を経て生成
- Persona API のZero retentionポリシーに準拠

### 「契約期間はどれくらいですか」
- 月額プラン: 最低3ヶ月
- 年額一括: 10%割引、最低1年

### 「料金以外のオプションは？」
- 初期セットアップ: 不要（Starter/Business）
- カスタムペルソナ作成: ¥150K-¥500K/プロジェクト
- 専属CS: Business以上に含む
- 導入研修: ¥300K (オプション)

### 「他社サービスとの違いは」
- 競合: 動画教材、SP研修、AIロープレ既存サービス
- 差別化: 行動データから再構成したペルソナの多様性、低遅延音声対話、業界専門家監修
